# Sources of the Chinook DDL

Chinook is a public sample schema of a digital media store (`https://github.com/lerocha/chinook-database`).

- License check, 2026-10-23: the GitHub API reports the repository's license as `NOASSERTION` ("Other"); it is not a recognised permissive license. Reading the license file would have needed a second network request, which was not made.
- So nothing was copied from the upstream repository. `sqlite.sql` and `postgres.sql` were written by hand from the public description of the schema: eleven tables (Artist, Album, Track, Genre, MediaType, Playlist, PlaylistTrack, Customer, Employee, Invoice, InvoiceLine), their columns, primary keys and foreign keys.
- No `INSERT` statements and no upstream rows. Rows are synthetic, generated by `../../seed/seed.py` with a fixed seed.
- Both files declare the same tables, keys and nullability; only type spellings differ (`NVARCHAR`/`DATETIME` in SQLite, `VARCHAR`/`TIMESTAMP` in PostgreSQL). Identifiers are quoted, so the mixed-case names survive on PostgreSQL.
