## 2026-10-27 - QCEW modelled on three engines

**Why.** QCEW is the second domain of FactModel M2: no row is about an individual, its hierarchies are code prefixes, and its code lists carry real defects. The model has to show all three with evidence.

- Seven entities (two data tables, five BLS code lists) from the SQLite catalog, reviewed with document evidence from the BLS layouts and the owner's profile.
- 46 probes run on SQLite; PostgreSQL and DuckDB give the same counts.
- Findings F-0001 to F-0009 and hazards H-0001, H-0002.
