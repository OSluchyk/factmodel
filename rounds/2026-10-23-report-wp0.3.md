## 5. Confirmed / inferred / unknown

**Confirmed**

- All checks green (section 3); 18 schemas meta-validate; templates ship in the wheel.

**Inferred** (my design choices, for owner review)

- `records` for inline evidence records and `evidence` for IDs everywhere, including the entity's own metadata evidence. The plan example used top-level `evidence:` for records; I changed it so one key never has two shapes.
- Register shapes: finding (`resolved` needs `resolution`, `evidence`, `closed_on`; `wont_fix` needs `decision`), escalation (`answered` needs `answer` with `source` and `evidence`; `withdrawn` needs a reason), hazard (`retired` needs `retired_on` and `retirement_evidence`), decision (`superseded` needs `superseded_by`; `retracts` lists evidence IDs).
- Profile facets: `evidence_status`, `mechanism`, `cardinality`, `any_end_class`, `all_ends_class`, `any_end_subject_scoped`, `all_ends_subject_scoped`, `all_ends_match`. A rule's `when` needs at least one facet, so there is no catch-all rule that would hide residue.
- A target set without a discriminator means per-tenant choice; its `join` is a map from target to join.
- The quote limit (40 words) is a regex; the pin check only requires `<something>@<version>`; per-kind pin formats are left to the loader.
- Layer, consumer, probe and trigger shapes are minimal; details come in M3 and WP1.6/WP1.7.

**Unknown**

- Whether `aggregation` in layers should become a vocabulary block (left as a slug until M3).

## 6. Divergences

- `src/factmodel/io/yaml_strict.py` (a WP1.1 deliverable) was written now: fixtures need a loader that keeps dates as strings. Round 4 reuses it.
- Maps use a schema for their values instead of `additionalProperties: false`: `measurement`, `ranks`, `per_environment`, `join` (target set), `vocabularies`, `expected`, snapshot `options`. They are maps by design.
- Forbidden keys render as `{not: {}}`, not `false`: jsonschema reports a `false` subschema at the parent's path, which hid the key in the error.
- `kind: snapshot` is a plain `const`; snapshot is not in `vocabulary:file_kind` (brief section 3 lists it apart).
- The fixtures were generated from valid examples by a scratch script (one mutation each); the script is not committed, the fixtures are.
- The owner mentioned the GitHub repository `https://github.com/OSluchyk/factmodel` during this round. No remote was added and nothing was pushed (D-008).
