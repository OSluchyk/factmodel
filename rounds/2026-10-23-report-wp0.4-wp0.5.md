## 5. Confirmed / inferred / unknown

**Confirmed**

- All checks green; every vector input validates against the round-2 schemas.

**Inferred** (algorithm choices the plan did not fix, for owner review)

- Effective status of a fact is the best of its records (`confirmed` > `inferred` > `unresolved` > `retracted`).
- The anchor entity is `direct` by definition. Scope runs before projection, because projection reads "subject scoped" ends.
- Transitive scope is a breadth-first fixed point; ties go to the lowest target level, then the lowest relationship reference. The basis reported is that of the first step.
- Target sets never carry scope (`target_set` rejection). A reference entity is always `none`.
- Reachability walks relationships both ways plus usable `anchor_reference` edges, skipping unresolved, retracted and derivation links.
- Rule 0: any residue target makes the whole relationship residue (one residue row per such target); `withheld` only when all targets have labels and they differ.
- Release key lists are top-level keys with `keep` and `drop`; the plan said "per-kind key allowlist" without saying how a key is dropped on purpose.
- Algorithm numbering follows the plan (1 projection, 2 scope, 3 release), although the core runs 2 before 1.

**Unknown**

- Whether release key lists need nested paths (for example a key inside each field). Top-level only for 0.1.

## 6. Divergences

- `release-allowlist` schema changed after round 2 (`keys.<kind>` is now `{keep, drop}`); fixtures regenerated with one new invalid case.
- The plan's "missing basis rejected" scope vector is now `missing-admission`: under D-007 there is no basis without an admission, so a missing admission means no propagation, not a rejection. Rejections are covered by `rejections`, `reference-blocks`, `direct` and `missing-admission`.
- Two new outputs beyond the plan: `generated/scope-rejections.tsv` and the `reachable` column in `generated/scope.tsv`.
- Vectors were generated by a scratch script from hand-written expectations; the script is not committed.
