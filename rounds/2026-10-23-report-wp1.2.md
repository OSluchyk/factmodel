## 5. Confirmed / inferred / unknown

**Confirmed**

- The algorithms match the 21 hand-written vectors; the three properties hold over all 18 model vectors.

**Inferred**

- The effective-status order is read from the order of `vocabulary:evidence_status` (best first), not typed in code. Reordering that block would change the algorithm; this is now a property of the vocabulary file.
- `fact project` writes a file only when its content changes, so timestamps stay stable for tools that watch `generated/`.
- `fact project` exits 0 when there is residue or a rejection; the gate (round 6) is what fails on them.

**Unknown**

- Performance on large models: not measured (the vectors are small). The scope loop is O(levels x steps).
